# Обновление и восстановление

[English version](UPDATE.md)

## Обычное обновление без UART

Когда OpenWrt нормально загружается, UART не нужен. В LuCI открой
**System, Backup / Flash Firmware**, загрузи только файл
`*-squashfs-sysupgrade.bin` и не снимай галочку **Keep settings**.

Через SSH сначала проверь образ, а потом запускай обновление:

```sh
sysupgrade -T /tmp/openwrt-mediatek-filogic-keenetic_kn-4010-squashfs-sysupgrade.bin
sysupgrade /tmp/openwrt-mediatek-filogic-keenetic_kn-4010-squashfs-sysupgrade.bin
```

Этот путь рассчитан на разделы `kernel` и `ubi` внутри `firmware_1`. Второй
слот не должен затрагиваться. Первое полноценное обновление `sysupgrade` на
этом порте ещё стоит проверить с подключённым UART и готовым raw-slot образом.

## Что останется после обновления

Обычный `sysupgrade` возвращает конфигурацию из `/etc/config`, SSH-ключи и
файлы, перечисленные в `/etc/sysupgrade.conf`. Произвольные файлы вне этого
списка не гарантированно сохраняются.

Дополнительно установленные пакеты не переносятся сами. Флаг `sysupgrade -k`
кладёт в резервную копию список пакетов, но не ставит их заново. Нужные пакеты
лучше включать в конфигурацию образа или держать рядом собственный список для
повторной установки. Особенно это касается модулей ядра.

## Если OpenWrt не загружается

Войди в U-Boot console и выбери второй слот, где лежит KeeneticOS:

```text
mw.b 0x46000000 0x55 1
mw.b 0x46000001 0x53 1
mw.b 0x46000002 0x54 1
mw.b 0x46000003 0x41 1
mw.b 0x46000004 0x01 1
mw.b 0x46000005 0x02 1
mw.b 0x46000006 0x01 1
mw.b 0x46000007 0x00 1
nand erase 0x3c00000 0x80000
nand write 0x46000000 0x3c00000 0x8
reset
```

Чтобы вернуться в OpenWrt, повтори блок выбора слота из
[УСТАНОВКА.md](УСТАНОВКА.md).
